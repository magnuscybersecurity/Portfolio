# GRC Portfolio

Hands-on GRC projects I'm building while working toward a career in governance, risk, and compliance. Everything here is based on a fictional fintech company (Meridian Pay) so I can practice real compliance work — scope statements, risk registers, audits — the same way it'd actually be done on the job.

More projects coming as I build them out.

## Projects

- **01 - ISMS Scope Statement** — defines the boundaries of Meridian Pay's information security program per ISO 27001 Clause 4.3: what's covered, what data it protects, and what's explicitly excluded and why.
